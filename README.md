# DEV@Deakin - Simple React + Tailwind P3

This is a beginner-friendly React/Vite version of the DEV@Deakin home page.

## Requirements

- Node.js installed
- VS Code or another code editor

## Run the project

Open the terminal inside this folder and run:

```bash
npm install
npm run dev
```

Open the localhost address shown by Vite.

## Main files

- `index.html` - starts the React application and loads Tailwind CDN.
- `src/main.jsx` - React entry point.
- `src/App.jsx` - components and page content.
- `.gitignore` - prevents `node_modules` from being committed.

## React concepts demonstrated

- Functional components
- Parent -> child component structure
- JSX
- `useState`
- Event handling
- Arrays
- `map()`
- Tailwind utility classes

## Important

`node_modules` is intentionally not included. Run `npm install` after extracting the ZIP.
